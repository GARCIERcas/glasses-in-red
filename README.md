# Glasses in Red — прототип приложения

Сеть платных велокоридоров Москвы в формате «такси-приложения» для велосипедиста:
выбрал, куда едешь → маршрут через красные коридоры → оплата (90 ₽ за въезд или 1500 ₽ в месяц) →
шлюз открывается по телефону → пошаговая навигация в коридоре → после коридора навигация по обычным улицам → SOS-механик в пути.

## Запуск

Самый простой способ — открыть `index.html` двойным кликом. Нужен интернет: Яндекс Карты, шрифт, поиск адресов
и маршруты по улицам загружаются из сети.

Или через встроенный мини-сервер (без Node и Python):

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

После этого откройте http://localhost:5173. Чтобы выложить приложение в интернет, загрузите всю папку на любой
статический хостинг (GitHub Pages, Netlify или ваш текущий).

### Ключ Яндекс Карт

Карта — официальный JavaScript API Яндекс Карт 2.1. Для показа на защите он работает и без ключа.
Для публикации в интернете получите бесплатный ключ на https://developer.tech.yandex.ru
(«JavaScript API и HTTP Геокодер») и впишите его в `YANDEX_API_KEY` в `js/config.js`.

## Как устроена навигация

Маршрут состоит из участков (`legs`), на карте и в интерфейсе у каждого свой цвет:

- **синий** — обычные улицы: до шлюза и от шлюза до цели. Повороты и названия улиц приходят из Valhalla.
- **красный** — красный коридор. Шаги: въезд через шлюз, переходы между коридорами на развязках, выезд.
- **серый** — уже проехали.

Баннер сверху показывает режим, расстояние до манёвра, что сделать, улицу и следующий манёвр.
Кнопка «Сойти с коридора» выводит через ближайший шлюз впереди и перестраивает остаток пути по улицам.

## Интерфейс на телефоне

- Главный экран: поиск, мои места (Дом, Учёба, Парк Горького) и категории «куда поехать» —
  Кафе, Рестораны, Бары, Парки, Музеи, Кино, Продукты, Велосервис. Категория показывает ближайшие места
  списком и метками на карте; нажали — строится маршрут.
- Шторку можно тянуть за ручку. На главном экране свайп вверх раскрывает остальное: ближайший шлюз, подписку,
  шлюзы рядом, состояние сети, приглашение друга, корпоративный доступ и статистику месяца.
  На остальных экранах свайп вниз сворачивает шторку, и видна вся карта.
- Анимации (`css/animations.css`): появление содержимого лесенкой, «вдавливание» кнопок, прорисовка маршрута
  на карте, «выпрыгивающие» метки, смена манёвра в навигаторе, конфетти по прибытии.
  Отключаются, если в системе включено «уменьшить движение».
- Геопозиция: по умолчанию демо-точка у Таганской площади (`DEMO_LOCATION` в `js/config.js`). Кнопка «Где я»
  пробует настоящий GPS — если вы в Москве, приложение берёт его.
- В настройках работают голосовые подсказки (озвучка браузером) и вибрация перед манёвром.
## Внешние сервисы

| Что | Сервис | Если недоступен |
|---|---|---|
| Карта | Яндекс Карты JS API 2.1 | приложение покажет «Карта не загрузилась» |
| Маршруты по улицам | Valhalla, valhalla1.openstreetmap.de | улицы рисуются пунктиром напрямую, время примерное |
| Поиск адресов, адрес под булавкой, места по категориям | Photon, photon.komoot.io | работают только популярные места, у булавки — координаты |
| Геометрия коридоров | вшита в `js/data/corridors.js` | сеть от внешних серверов не зависит |

### Пересобрать коридоры

Если поменяли шлюзы или коридоры в `js/data/network.js`:
1. Удалите `js/data/corridors.js` (или очистите в нём `edges`).
2. Запустите `serve.ps1` и откройте приложение — геометрия построится через Valhalla.
3. Сохраните её в консоли браузера:
   `fetch('/__save-corridors', {method: 'POST', body: JSON.stringify(GIR.net.exportGeometry())})`

## Что условно

- Сеть коридоров придумана для демонстрации: 12 коридоров, 67 шлюзов и 16 SOS-хабов в центре — Садовое и Бульварное
  кольца, набережные, радиальные улицы — внутри ТТК и немного за ним. Механики тоже условные.
- Коридоры идут вдоль улиц, но выпрямлены: без петель, разворотов и объездов площадей (на сложных развязках —
  мосты и эстакады). Выпрямление делается при загрузке (`straighten` в `js/services/network.js`), а в
  `js/data/corridors.js` хранится исходная геометрия по улицам.
- Если по улицам заметно быстрее (короткая поездка), приложение честно ведёт по улицам без коридора.
- Участки по улицам строятся по пешеходной сети: велопрофиль соблюдает все односторонние улицы и в центре даёт крюки в 3–5 раз.
- Время в пути: в коридоре ~25 км/ч без остановок, на улицах ~12 км/ч со светофорами (`js/config.js`).
- Оплата в демо-режиме, деньги не списываются.
- Поездка симулируется в ускоренном режиме (×1 / ×2 / ×4). Время прибытия считается по «часам симуляции» и
  сдвигается только после SOS или если сойти с коридора.
